# GPF Journal (เวอร์ชันใช้งานอิสระ)

สมุดบัญชี กบข. ส่วนตัว ใช้ได้โดยไม่ต้องล็อกอินอะไร เปิดบนมือถือหรือคอมได้

- อ่านไฟล์ PDF ใบแจ้งยอดจากแอป My GPF ได้ทุกปี แล้วคำนวณหน่วย มูลค่า เงินต้น และกำไรขาดทุนให้อัตโนมัติ
- ผลตอบแทนรายสัปดาห์ รายเดือน ตั้งแต่ต้นปี ตั้งแต่เริ่ม และ IRR ต่อปี
- แผนการลงทุนในอดีต พร้อมผลของการย้ายแผนแต่ละครั้ง
- จัดอันดับและเปรียบเทียบทุกแผนจาก NAV ที่ กบข. ประกาศ
- บันทึกเงินนำส่งรายเดือน การเปลี่ยนแผน และตรวจยอดกับ My GPF
- โหมดซ่อนจำนวนเงินสำหรับแคปหน้าจอ และโหมดสว่าง/มืด

**ความเป็นส่วนตัว:** ข้อมูลพอร์ตอยู่ในเบราว์เซอร์ของเครื่องที่ใช้เท่านั้น ไฟล์ PDF อ่านในเครื่อง ไม่มีการส่งขึ้นเซิร์ฟเวอร์ ในโฟลเดอร์นี้ไม่มีข้อมูลส่วนตัวของใคร จึงแชร์ให้เพื่อนใช้ได้เลย แต่ละคนเห็นเฉพาะข้อมูลของตัวเอง

---

## วิธีที่ 1: ขึ้นเว็บฟรีด้วย GitHub Pages (แนะนำ, NAV อัปเดตเอง)

1. สมัคร https://github.com (ฟรี)
2. กด **New repository** ตั้งชื่อเช่น `gpf-journal` เลือก **Public** แล้วกด Create
3. กด **uploading an existing file** แล้วลากไฟล์และโฟลเดอร์ทั้งหมดในโฟลเดอร์นี้ไปวาง (`index.html`, `sw.js`, `manifest.webmanifest`, `data`, `icons`, `vendor`, `scripts`) แล้วกด Commit
4. โฟลเดอร์ `.github` เป็นโฟลเดอร์ซ่อน บางเครื่องลากไม่ติด ให้สร้างเอง: **Add file → Create new file** พิมพ์ชื่อ `.github/workflows/update-nav.yml` แล้วคัดลอกเนื้อหาจากไฟล์ `github-workflow/update-nav.yml` ในโฟลเดอร์นี้ไปวาง (เป็นไฟล์เดียวกัน แยกไว้ให้เพราะ Windows มักซ่อนโฟลเดอร์ที่ขึ้นต้นด้วยจุด) อัปเสร็จแล้วลบโฟลเดอร์ `github-workflow` ทิ้งได้
5. ไปที่ **Settings → Pages** ช่อง Branch เลือก `main` และ `/ (root)` แล้วกด Save รอ 1–2 นาทีจะได้ลิงก์ เช่น `https://ชื่อคุณ.github.io/gpf-journal/`
6. ไปที่แท็บ **Actions** กดเปิดใช้ แล้วเลือก "อัปเดต NAV จาก กบข." → **Run workflow** เพื่อลองรันครั้งแรก ระบบจะรันเองทุกวันเวลา 08:47 และ 19:47 น.

ส่งลิงก์ให้เพื่อนได้เลย เพื่อนเปิดแล้วจะเห็นหน้าเริ่มต้น ให้นำเข้า PDF ของตัวเอง

> ถ้า Actions ดึงเว็บ กบข. ไม่สำเร็จ (บางครั้งเว็บไทยจำกัดการเข้าถึงจากต่างประเทศ) ยังอัปเดตเองได้ที่หน้า **บันทึก → อัปเดต NAV** โดยคัดลอกข้อความจากเว็บ กบข. มาวาง หรือเลือกไฟล์ Excel

## วิธีที่ 2: ใช้บนคอมเครื่องเดียว

ดับเบิลคลิก `index.html` เปิดในเบราว์เซอร์ได้เลย แต่ NAV จะไม่อัปเดตเอง และการอ่าน PDF ต้องต่ออินเทอร์เน็ต (โหลดตัวอ่าน PDF ชั่วคราว) แนะนำวิธีที่ 1 มากกว่า

## เริ่มใช้งาน

**1. ดาวน์โหลด PDF จากแอป My GPF** (แอปให้ย้อนหลังได้สูงสุด 5 ปี)

1. เปิดแอป My GPF → แท็บ **My Account** → **ดูยอดเงินย้อนหลังรายปี**
2. แท็บ **ตามประเภทเงินนำส่ง**: ทุกปี กด **ดาวน์โหลด** ทั้ง 2 ปุ่ม คือ "ดูยอดเงิน" (ไฟล์ `BalanceTransaction_…`) และ "ดูรายละเอียดรายการ"
3. แท็บ **ตามแผนการลงทุน**: ทุกปี กด **ดาวน์โหลด** ทั้ง 2 ปุ่ม คือ "ดูรายละเอียดรายการ" (ไฟล์ `TransactionUnitDetail_…`) **สำคัญที่สุด** และ "ดูยอดเงิน" (ไฟล์ `TransactionUnit_…` จำนวนหน่วยแต่ละแผน)
4. รวม 4 ไฟล์ต่อปี × 5 ปี = 20 ไฟล์ (ปีในชื่อไฟล์เป็น ค.ศ.)

| ไฟล์ | ใช้ทำอะไร | จำเป็นไหม |
|---|---|---|
| ตามแผนการลงทุน → ดูรายละเอียดรายการ | หน่วย NAV เงินนำส่ง การย้ายแผน | จำเป็น |
| ตามประเภทเงินนำส่ง → ดูยอดเงิน | เงินต้นยกมา ยอดสิ้นปี เงินสะสม/สมทบ/ชดเชย | แนะนำมาก |
| ตามแผนการลงทุน → ดูยอดเงิน | จำนวนหน่วยแต่ละแผนสิ้นปี ใช้ตรวจหน่วยและยอดยกมา | แนะนำ |
| ตามประเภทเงินนำส่ง → ดูรายละเอียดรายการ | เงินนำส่งรายเดือนแยกประเภท | ไม่บังคับ |

**2. เปิดแอป กด "นำเข้า PDF" แล้วเลือกทั้งหมดพร้อมกัน**

ไม่จำเป็นต้องมีไฟล์ตั้งแต่ปีแรกที่เป็นสมาชิก เงินที่สะสมก่อนช่วง 5 ปีจะคิดเป็น **ยอดยกมา** ให้อัตโนมัติ โดยใช้รายการย้ายแผนและไฟล์ "ดูยอดเงิน" ของปีแรก แล้วตรวจกับยอดสิ้นปีให้ ถ้ามีตัวเลขจริงจาก My GPF แก้ได้ที่ **บันทึก → ยอดยกมา**

**3. ทุกเดือน** กด **บันทึก → เงินนำส่งเดือนนี้** หรือรอนำเข้า PDF ปีใหม่ตอนต้นปี แอปจะใช้ตัวเลขจาก PDF แทนรายการที่บันทึกเองโดยไม่นับซ้ำ

**อยากเริ่มใหม่:** ไอคอนตั้งค่า → **ล้างข้อมูลพอร์ต** หรือติ๊ก "ล้างข้อมูลเดิมทั้งหมดก่อนนำเข้า" ในหน้านำเข้า PDF

**ติดตั้งเป็นแอปบนมือถือ:** iPhone ใช้ Safari กดแชร์ → "เพิ่มไปยังหน้าจอโฮม" ส่วน Android ใช้ Chrome กด ⋮ → "ติดตั้งแอป" การติดตั้งช่วยไม่ให้เบราว์เซอร์ลบข้อมูลทิ้งเมื่อไม่ได้เปิดนาน

**สำรองข้อมูล:** กดไอคอนตั้งค่า → **สำรองข้อมูล (JSON)** เก็บไฟล์ไว้ในไดรฟ์ เวลาเปลี่ยนเครื่องให้กด **กู้คืนจากไฟล์** แอปจะเตือนถ้าไม่ได้สำรองเกิน 30 วัน

## ไฟล์ในโฟลเดอร์

| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | ตัวแอปทั้งหมด |
| `data/nav.json` | NAV ที่ดึงอัตโนมัติ (GitHub Actions เขียนให้) |
| `data/news.json` | ข่าว (ว่างไว้ ใส่เองได้ รูปแบบดูในโค้ด `renderNews`) |
| `vendor/` | ตัวอ่าน PDF (pdf.js, Apache-2.0) |
| `scripts/update_nav.py` + `.github/workflows/update-nav.yml` | ตัวดึง NAV จากเว็บ กบข. |
| `sw.js`, `manifest.webmanifest`, `icons/` | ทำให้ติดตั้งเป็นแอปและเปิดได้ตอนออฟไลน์ |

ตัวเลขทางการให้ยึดตามแอป My GPF ของ กบข. แอปนี้ช่วยติดตามและวิเคราะห์เท่านั้น ไม่ใช่คำแนะนำการลงทุน
